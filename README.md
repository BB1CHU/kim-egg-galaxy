# 김계란의 휴대폰을 주웠습니다

김계란의 휴대폰을 자유롭게 둘러보는 관람형 웹 콘텐츠의 검토용 수정본입니다.

## 확인 방법

폴더 전체를 내려받은 뒤 `index.html`을 브라우저로 엽니다. 폴더 구조를 그대로 유지해야 사진과 영상이 표시됩니다. GitHub Pages에도 별도 빌드 없이 배포할 수 있습니다.

잠금화면을 클릭하거나 위로 쓸어올린 뒤 PIN `0000`을 입력합니다. PIN은 체험용 연출입니다.

## 적용 내용

- 카카오톡: PD, 공혁준, QWER, 헤비 Hebi, 자기♥ 다섯 방의 준비된 대화 읽기. 답장·선택지·미션 없음.
- 공혁준: 운동 브이로그와 주말 약속 대화 모두 포함. 호칭은 혁준상/계란님.
- QWER: 최신 회식 메뉴 대화와 마젠타 전화. 예전 단체사진·합주 버전은 적용하지 않음.
- 갤러리: 식사 사진 6장, 일상 사진 5장, 소중한 순간 영상 3개. 사진·영상 확대, 이전/다음 이동.
- 카메라: 제공된 8.3초 셀카풍 영상 무음 반복 재생. 실제 카메라 권한이나 촬영·저장 기능 없음. 셔터 버튼은 화면 효과만 표시.
- Samsung Notes: 오늘 할 일, 퇴근 후 먹을 것, 장보기, 횐님들, 맛있는 것들 다섯 메모.
- 전화: 준비된 대사를 자막으로 재생. 실제 전화 연결·음성 녹음·음성 복제 없음.
- 시간차 연락: 잠금 해제 후 사이트가 보이는 동안 PD 30초, 공혁준 65초, 마젠타 수신전화 100초, 헤비 145초. 전화는 받기/거절 가능하며 놓쳐도 탐색에 불이익 없음.
- 설정: 다크 모드, 실버/차콜 배경화면, 메시지 알림, 처음부터 다시 보기.
- 기존 YouTube·Instagram·인터넷 링크 유지.

## 파일

- `index.html`, `style.css`: 원본 갤럭시 화면 구조와 수정 디자인
- `app.js`: 화면 이동·읽기·재생·시간차 연락
- `content.js`: 카톡·메모·전화 대사. 문구 수정은 이 파일에서 진행
- `assets.js`: 사진·영상 경로, 앨범 구성
- `base.js`: 기존 아이콘과 외부 공개 콘텐츠 링크
- `assets/images`, `assets/thumbs`: 사진 원본 비율 유지한 최적화 사본과 썸네일
- `assets/videos`, `assets/posters`: 무음 영상과 포스터
- `assets/verification.json`: 영상 형식·음성 제거 검증 기록

## 안내

실제 사적인 카톡이나 휴대폰 기록을 공개한 것이 아니라, 체험을 위해 구성한 가상 대화·메모·통화입니다. 공개 콘텐츠의 관계성을 참고한 창작 대본이 포함됩니다. 메모의 운동·식사 기록은 개인별 처방이 아닙니다.

사진·영상은 사용자가 제공한 자료로 구성했습니다. 원본 첨부파일은 변경하지 않았습니다. 배포용 영상 4개에는 음성 스트림이 없습니다. 카메라 영상은 H.264/yuv420p로 변환했고 나머지 영상은 H.264 무음 사본입니다.

다크 모드(`egg-theme`)와 배경화면(`egg-wall`)만 브라우저에 저장합니다. 기존 `egg-memo` 데이터는 읽거나 덮어쓰지 않습니다. 새 메시지·통화 기록은 체험 세션 내에서만 유지되며 새로고침/처음부터 다시 보기로 초기화됩니다.

현재 검토용 브랜치용 파일입니다. `main` 병합과 공개 Pages 배포는 화면 및 자료 확인 후 별도로 진행합니다. 새 브랜치만으로 별도 미리보기 주소가 자동 생성되지는 않습니다.
