# 김계란의 갤럭시

김계란과 피지컬갤러리의 **공개 콘텐츠**를 탐색하는 갤럭시 스타일 비공식 팬메이드 웹사이트입니다.

## 사용 방법

1. 잠금화면을 클릭하거나 위로 쓸어올립니다.
2. 체험용 PIN **0000**을 입력합니다.
3. YouTube, Instagram, 갤러리, Samsung Notes, 인터넷, 설정 앱을 탐색합니다.

## 구성

- `index.html`: CSS·JavaScript가 포함된 단일 웹사이트 파일
- 공개 YouTube 영상 4개와 Instagram 게시물 6개 원문 연결
- 영상 검색·분류, 공개 썸네일 앨범, 팬 정리 노트
- 다크 모드, 실버·차콜 배경화면, 최근 열어본 앱
- 사용자가 작성하는 내 메모: 브라우저의 로컬 저장소에만 보관

별도 설치나 빌드 없이 GitHub Pages로 배포할 수 있습니다. 파일을 브라우저에서 직접 열 수도 있습니다. 썸네일, 영상, 외부 링크는 인터넷 연결이 필요합니다. 영상 임베드가 제한되는 환경에서는 원본 YouTube 링크를 이용하세요.

## 안내와 출처

실제 개인 휴대폰이나 사적인 대화·통화·일정·운동 기록을 재현하지 않습니다. PIN은 화면 연출용으로, 실제 보안 기능이 아닙니다. 배터리와 통신 아이콘은 디자인 예시입니다. 특정 갤럭시 기종의 정확한 복제나 삼성 공식 서비스가 아닙니다.

Samsung Notes의 자료는 공개 게시물을 정리한 팬 노트입니다. 운동 처방이나 의료 조언을 제공하지 않습니다.
